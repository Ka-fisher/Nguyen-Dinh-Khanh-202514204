I, Bài toán
 Tìm tích lớn nhất của 2 phần tử trong 1 mảng số nguyên cho trước.

II, Giải thuật 
  - Sắp xếp mảng số nguyên theo thứ tự tăng dần.
  - Khi đó tích lớn nhất của 2 phần tử chỉ có thể là tích giữa 2 phần tử nhỏ nhất hoặc giữa 2 phần tử lớn nhất.

III, Test case:
 1, Test case 1:
  -Input:
   n = 5
   A[] = { -2, 6, 0, 5, 8}

  - Output:
	Max product is 48 = 8 * 6

 2, Test case 2:
  - Input:
	n = 5
	A[] = { -10, -9, 8, 7, 6}
  - Output:
	Max product is 90 = -10 * -9

 3, Test case 3:
   - Input:
	n = 3
	A[] = { 1, 1, 1}
  - Output:
	Max product is 1 = 1 * 1

 4, Test case 4:
   - Input:
	 n = -1
   - Output:
	 Please enter an positive number!
 5, Test case 5:
    - Input:
	n = 3
	A[] = { -10, 0, 10}
  - Output:
	Max product is 0 = -10 * 0 = 0 * 10
